# SmartHome-Automation Enterprise

[![Release](https://img.shields.io/github/v/release/Ali-Marandi/SmartHome-Automation)](https://github.com/Ali-Marandi/SmartHome-Automation/releases)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**SmartHome-Automation** is a commercial-grade, local-first home automation platform designed for high-performance and enterprise security. Built with **Tauri**, **React**, and **Rust**, it provides a beautiful and responsive Windows desktop experience.

## 🚀 Key Features
- **Advanced Dashboard**: Real-time status and interactive widgets.
- **Enterprise Security**: Role-Based Access Control (RBAC) and local-first data processing.
- **Multi-Protocol Support**: Matter, Zigbee, Z-Wave, and MQTT.
- **AI Integration**: Natural language control via local LLMs.
- **Energy Insights**: Detailed analytics and predictive reporting.

## 🛠 Tech Stack
- **Framework**: [Tauri v2](https://v2.tauri.app/)
- **Frontend**: React 19, TypeScript, Tailwind CSS, Shadcn UI
- **Backend**: Rust
- **Database**: SQLite
